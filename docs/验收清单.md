## C. 已知落差（不粉饰）

1. **一次性粘贴无法彻底消除**：`allow-external-apps` 是 Termux 官方刻意设的死门槛，
   无 root 时 shell 读不到私有目录、ContentProvider 写被强制只读、所有执行入口都卡这道检查。
   那些 AI 手机 App 也一样。**最多粘贴一次**，之后永久全自动；Shizuku root 模式也只是
   「权限自动开好、少弹框」，并不能免掉这次准备（13.1.5 已移除 `newProcess`，App 无公开 API
   静默写 Termux 私有目录）——不粉饰成「root 全程零命令」。
2. **形态**：服务端跑在 Termux 里，APK 是界面壳，不是零等待瞬时启动。
3. **权限范围克制**：本 App 只申请自己真正需要的权限（RUN_COMMAND、通知、电池白名单），
   **不申请无障碍 / 悬浮窗 / 模拟点击**——那些是"操控手机"类 App 才需要的，加了反而骚扰用户。
4. **工具调用**：B12 很可能失败，App 会退化成多 bot 聊天壳。
5. **定时任务**：Doze 下锁屏数小时后不准点。
6. **本地服务需自己起**：本地模型 / TTS / 绘图不会有现成服务，必须显式启动并确认端口。
7. **Shizuku 反射授权属"尽力而为"**：`grantRuntimePermission` 在部分国产 ROM 的
   shell(2000) 模式可能被拒，此时自动回落到系统授权框 / 权限页，不影响使用。
