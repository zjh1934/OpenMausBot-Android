## C. 已知落差（不粉饰）

1. **形态**：服务端跑在 Termux 里，APK 是界面壳。所以「点开即用」含一个
   "首次自动拉起服务、等几秒"的过程，不是零等待瞬时启动。
2. **工具调用**：B7/B9 很可能失败，App 会退化成多 bot 聊天壳。
   这不是安装问题，是当前上游对 `openai-compat` 模型的能力限制。
3. **定时任务**：Doze 下锁屏数小时后不准点。
4. **桌面专属能力**已砍：控制宿主桌面、本地 VM/云电脑、原生听写、桌面 CLI 引擎。
5. **本地服务需自己起**：实测手机上 8080/11434/1234/4123 当时全空，
   本地模型 / TTS / 绘图不会有现成服务可用，必须显式启动并确认端口与接口形态。
