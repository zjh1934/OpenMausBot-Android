# 大白话使用说明

你只需要做两件事：**准备一次**，**以后点开就用**。

---

## 第一步：准备（只做一次，大概几分钟）

### 1. 装 Termux

手机上装 **Termux**。注意：要用 **GitHub 或 F-Droid 版**，
不要用应用商店里那个已经停更的老版本（会有兼容问题）。

### 2. 把 5 个文件放进手机

从这个项目里找到 `termux` 文件夹，里面有 5 个文件：

```
install.sh
start-omb.sh
omb-shim.cjs
patch-dist.mjs
config.template.json
```

把它们放到手机上一个你能找到的地方（比如「下载」文件夹里建个 `mausbot` 文件夹）。

### 3. 跑一次安装

打开 Termux，粘贴这一行，回车：

```bash
cd ~/storage/downloads/mausbot && bash install.sh
```

（如果文件放在别处，把路径换成实际位置。）

然后**什么都别做，等它自己跑完**。屏幕会一直滚字，可能要几分钟。
看到 `安装完成` 或 `服务已在运行` 就好了。

这一步它帮你做了：把 Termux 更新到最新、装好运行环境、装好聊天软件、
**打上一个安卓专用的补丁**（这个补丁不加，软件在手机上根本打不开）、
以及允许桌面图标一键启动。

### 4. 装 APK

从项目的 GitHub 页面 → **Actions** → 点最新一次运行 → 下载
`MausBot-本地版-APK` 里的 `MausBot-本地版-debug.apk`，点开安装。

手机可能会提示「未知来源」，允许一次就行。

---

## 第二步：以后怎么用

**点开桌面上的「MausBot 本地版」图标。**

- 第一次点开：会自动启动后台服务，等几秒（一般 5～15 秒）就进入聊天界面。
- 之后每次点开：如果服务还在，直接就进去了。

聊天界面就是原本 PC 上那个界面，能在里面建不同的 bot、给它们设人设、
换模型、群聊、看记忆。**你的聊天记录只存在手机里**，不会上传到任何地方。

---

## 如果点开一直转圈，进不去

引导页上有个「启动不了？看这里」，展开照做。常见的三件事：

1. **彻底关掉 Termux 再重开一次**
   （安装时改了一个设置，要重开才生效）。
2. 确认 Termux 里跑过一次 `bash install.sh`。
3. 还不行就点引导页的「**复制启动命令**」，自己打开 Termux 粘贴回车，
   再回到 App 点「重新检测」。

还不行的话，打开 Termux 看一眼日志：

```bash
tail -40 ~/.openmausbot/serve.log
```

---

## 关于"能不能一直后台跑"

- 想让它在后台稳一点：**锁住 Termux 的最近任务卡片**（在多任务界面往下拉一下），
  再把 Termux 的省电设置改成「无限制」、允许自启动。
- 手机**长时间插着电**用更稳，本地跑模型比较耗电发热。
- 实话实说：手机灭屏放几个小时后，系统为了省电会冻住后台，
  **定时提醒这类任务不一定准点**。聊天记录和服务不会丢，
  重新点开图标就能接着用。

---

## 关于接你手机里的本地小模型

这一步是**可选**的，不接也能用（可以用云端 API，或者先只聊天）。

软件里默认已经准备好了两个"位置"：一个留给手机本地的小模型，
一个留给云端。要接本地模型，需要你在 Termux 里额外起一个服务，
具体怎么起、怎么填，写在 `termux/README.md` 的「本地模型怎么接」那一节。

> 有个事要提前说清楚：目前这类"外部模型"接进来，主要是**纯聊天**。
> 原来电脑上那些"弹审批卡让你点允许/拒绝""在聊天里画图"的功能，
> 可能会用不上。这是上游目前的限制，不是装错了，也别以为哪里坏了。

## 几个常见疑问

**问：要联网吗？**
答：不用。服务就在你手机里跑，断网也能聊（前提是你接的是本地模型）。
只有你自己填了云端 API Key 才会走网络。

**问：会不会把我的聊天内容传出去？**
答：不会。本项目所有服务只监听手机本机地址 `127.0.0.1`，
不对局域网和公网开放。

**问：软件更新了怎么办？**
答：在 Termux 里重新跑一次 `bash install.sh` 就行，
它不会删你的聊天记录和已填好的配置。

**问：桌面图标能改名换图标吗？**
答：能，但要在源码里改了重新打包。当前的叫「MausBot 本地版」，蓝色气泡图标。
